# Inventory & Order Management System

## 1. Project Overview

The Inventory & Order Management System (IOMS) is a backend application developed using Java and Spring Boot.

It is designed to manage products, inventory, customers, orders, and payments for an e-commerce business.

The application aims to provide centralized inventory tracking, reliable order processing, and secure user management.

## 2. Problem Statement

Small and medium-sized businesses often manage products, stock quantities, and customer orders using spreadsheets or disconnected systems.

This can result in:
- Incorrect inventory quantities.
- Duplicate or inconsistent orders.
- Difficulty tracking customer purchases.
- Manual stock management.
- Poor visibility into sales performance.

This project aims to solve these problems through a centralized backend application.

## 3. Project Objectives

- Centralize product and category management.
- Maintain accurate inventory records.
- Implement secure customer authentication.
- Provide reliable order processing.
- Maintain consistent payment records.
- Generate inventory and sales reports.
- Apply real-world backend development practices.

## 6. User Roles

### Administrator
- Manage products and categories.
- Update inventory.
- View customer orders.
- Manage order statuses.
- View business reports.

### Customer
- Register and log in.
- Browse products.
- Check product availability.
- Place orders.
- View order history.
- Cancel eligible orders.

## 7. Project Scope

The initial version will focus on implementing core inventory and order management functionality.

Advanced features such as payment gateway integration, email notifications, caching, and multi-warehouse support will be considered future enhancements.
